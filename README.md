# SmartCart Segmentation System

A customer segmentation project using exploratory data analysis and clustering to identify groups of customers with similar characteristics.

## Notebook

`smartcart.ipynb` covers data preprocessing, missing values, feature engineering, column selection, outlier review, correlation heatmaps, encoding and scaling, visualization, selecting a cluster count with the elbow method and silhouette score, clustering, and characterizing the resulting segments.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- pandas, NumPy, seaborn, Matplotlib, and scikit-learn

Install the dependencies with:

```bash
pip install jupyter pandas numpy seaborn matplotlib scikit-learn
```

## Run

Keep `smartcart_customers.csv` beside the notebook locally, then open `smartcart.ipynb` in Jupyter and run the cells.

## Dataset

The customer dataset is intentionally excluded from version control. Obtain it separately and save it as `smartcart_customers.csv` beside the notebook before running the project.
